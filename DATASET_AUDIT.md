## Download decision

The initial implementation will contain download and preparation scripts but will not silently download restricted or ambiguously licensed data. The first operational path will prefer a source whose record explicitly states research-use terms and whose downloaded metadata can be audited. If no candidate passes the complete licence/provenance check without user acceptance, the application will still be fully implemented with model-loading and sample-data pathways, while training commands remain reproducible and clearly report the missing dataset-access prerequisite.

The volumetric segmentation path will target BraTS-compatible data because the official BraTS page documents the modalities, NIfTI format, expert annotations, and preprocessing assumptions [1]. The model card will state that this does not establish performance on meningioma or pituitary tumors. The classification path will use a verified four-class source only after checking duplicate, patient, class, and licence metadata; supplied train/test folders will not be trusted as an untouched test set until independently audited.

## Planned audit outputs after authorized download

The preparation script will produce a manifest with anonymized patient ID, file path, class, modality, source, split, mask availability, dimensions, spacing, and checksum. It will calculate exact class counts, patient counts, file hashes, perceptual-hash near duplicates, corrupted-file counts, image-quality summaries, and split overlap. These reports will be committed without raw data or identifying metadata.
