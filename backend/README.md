# FastAPI Inference Service

This directory contains the separately runnable FastAPI service for secure image/volume validation, optional experimental classification inference, real Grad-CAM generation, segmentation utilities, measurement, PDF report construction, and safe contextual-chat support. It remains separate from the managed application server because Python scientific packages, NIfTI/DICOM utilities, and model artifacts have a different deployment profile from the dashboard.

The default local service exposes honest `model_unavailable` states. When explicitly configured with the EXP-005 checkpoint and validation-only calibration record, it returns a real experimental four-class classifier result, a **model confidence score** (never a medical probability), and a real Grad-CAM overlay. `api/index.py` is a Vercel-specific academic-demo entry point: it downloads only the SHA-256-verified public EXP-005 artifact URLs, has no raw MRI data, and starts with only the known development and localhost CORS origins. The exact final dashboard HTTPS origin must replace the development origin before public browser use.
