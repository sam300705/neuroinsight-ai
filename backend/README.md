# FastAPI Inference Service

This directory contains the separately runnable FastAPI service for secure image/volume validation, optional experimental classification inference, real Grad-CAM generation, PDF report construction, and safe contextual-chat support. Mode B segmentation, measurement, and 3D outputs remain unavailable. The service remains separate from the managed application server because Python scientific packages, NIfTI/DICOM utilities, and model artifacts have a different deployment profile from the dashboard.

The default local service exposes honest `model_unavailable` states. When explicitly configured with the EXP-005 checkpoint and validation-only calibration record, it returns a real experimental four-class classifier result, a **model confidence score** (never a medical probability), and a real Grad-CAM overlay. `api/index.py` is a Vercel-specific academic-demo entry point: it downloads only checksum-verified EXP-005 artifacts, has no raw MRI data, and defaults CORS to the verified managed dashboard HTTPS origin plus localhost development origins. If artifact retrieval, checksum validation, metadata, or ONNX initialization fails, the service stays available but reports Mode A as unavailable rather than crashing the whole function.
